# Pemeriksaan Penunjang Diabetes

## Jenis Tes Gula Darah

### 1. Gula Darah Sewaktu (GDS)
- Tes dilakukan kapan saja tanpa perlu puasa.
- Normal: < 140 mg/dL.
- Indikasi DM: >= 200 mg/dL (jika disertai gejala klasik).

### 2. Gula Darah Puasa (GDP)
- Puasa minimal 8 jam sebelum tes.
- Normal: < 100 mg/dL.
- Prediabetes: 100-125 mg/dL.
- Diabetes: >= 126 mg/dL.

### 3. Tes Toleransi Glukosa Oral (TTGO)
- Puasa 8 jam, lalu minum larutan glukosa 75 gram.
- Cek gula darah 2 jam setelah minum.
- Normal: < 140 mg/dL.
- Prediabetes: 140-199 mg/dL.
- Diabetes: >= 200 mg/dL.

### 4. HbA1c (Glycated Haemoglobin)
- Mengukur rata-rata gula darah selama 2-3 bulan terakhir.
- Tidak perlu puasa.
- Normal: < 5.7%.
- Prediabetes: 5.7% - 6.4%.
- Diabetes: >= 6.5%.
- Target untuk pasien DM yang sudah terdiagnosis: umumnya < 7% (sesuai anjuran dokter).

## Pemeriksaan Lain yang Disarankan

1. **Profil Lipid**: Kolesterol total, LDL, HDL, Trigliserida.
2. **Fungsi Ginjal**: Ureum, Kreatinin, Laju Filtrasi Glomerulus (LFG), Albumin urine.
3. **Fungsi Hati**: Albumin, Globulin, SGOT, SGPT.
4. **Elektrokardiografi (EKG)**: Deteksi risiko jantung.
5. **Funduskopi**: Pemeriksaan retina mata untuk deteksi retinopati.
6. **Pemeriksaan Kaki**: Evaluasi vaskular, neuropati, ABI (Ankle-Brachial Index).

## Jadwal Pemantauan

| Kondisi | Frekuensi Cek |
|---|---|
| HbA1c (jika gula darah terkontrol) | Setiap 6 bulan |
| HbA1c (jika gula darah tidak terkontrol) | Setiap 3 bulan |
| Tekanan darah | Setiap kunjungan |
| Profil lipid | Minimal 1x/tahun |
| Fungsi ginjal | Minimal 1x/tahun |
| Funduskopi (mata) | Minimal 1x/tahun |
| Pemeriksaan kaki | Setiap kunjungan |

## Catatan Penting

- Hasil lab harus diinterpretasikan oleh DOKTER.
- AI hanya boleh memberikan informasi umum tentang nilai referensi.
- JANGAN mendiagnosis berdasarkan satu kali cek.
- JANGAN mengubah dosis obat berdasarkan hasil lab tanpa konsultasi dokter.
