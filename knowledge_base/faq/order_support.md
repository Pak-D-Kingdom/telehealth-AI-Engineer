# FAQ Order Support

## Cek Pesanan

Minta nomor order atau nomor telepon yang digunakan saat transaksi. Jika sistem order belum terintegrasi, buat tiket untuk CS.

## Paket Belum Sampai

Minta nomor order, nama penerima, kota/kecamatan, dan tanggal transaksi. Jika paket melewati estimasi, eskalasi ke CS.

## Produk Rusak atau Salah Kirim

Minta nomor order, foto produk, foto paket, dan kronologi singkat. Buat tiket retur/refund untuk CS.
