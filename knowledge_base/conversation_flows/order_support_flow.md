# Order Support Flow

Owner: Conversation Designer  
Last Updated: 2026-08-11

## Intent

- Cek status pesanan.
- Paket belum sampai.
- Salah produk.
- Produk rusak.
- Pembayaran bermasalah.
- Refund atau retur.

## Alur

1. Minta nomor order atau nomor telepon transaksi.
2. Validasi data minimum.
3. Cek status order jika integrasi tersedia.
4. Jika tidak tersedia, buat tiket CS.
5. Berikan ringkasan status dan estimasi tindak lanjut.

## Data Minimum Tiket

- Nomor order.
- Nama penerima.
- Channel kontak.
- Jenis masalah.
- Kronologi singkat.
- Bukti foto/video jika relevan.
