# Knowledge Base Chatbot Skincare Wajah

Folder ini berisi sumber pengetahuan utama untuk chatbot customer service skincare wajah. Semua jawaban bot sebaiknya dirujuk dari dokumen di sini agar konsisten, aman, dan mudah diaudit.

## Struktur Folder

- `brand/`: identitas brand, tone of voice, dan aturan komunikasi.
- `product/`: katalog produk, kandungan, cara pakai, dan rekomendasi.
- `skin_conditions/`: panduan concern kulit umum.
- `customer_service/`: FAQ operasional, order, komplain, dan template handoff.
- `policies/`: kebijakan pengiriman, retur, refund, privacy, dan disclaimer.
- `conversation_flows/`: alur percakapan bot.
- `safety/`: red flags, kontraindikasi, dan batasan jawaban bot.

## Aturan Update

- Gunakan tanggal update pada setiap file.
- Jangan menambahkan klaim medis tanpa validasi ahli.
- Update harga, stok, promo, dan BPOM hanya dari sumber resmi internal.
- Setiap perubahan besar harus dites dengan contoh percakapan.
